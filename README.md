# Go Backend Roadmap

Интерактивная карта для изучения Go-бэкенда с нуля до первой работы.

**Открыть: https://ubicasmerti228.github.io/go-roadmap/**

## Что внутри

Карта состоит из восьми этапов. Сквозной проект TaskFlow растёт вместе с ними — от CLI до системы из двух сервисов.

| № | Этап | Что собираешь |
|---|------|---------------|
| 0 | Абсолютный ноль | репозиторий и первая программа |
| 1 | Фундамент Go | TaskFlow v0.1 — CLI и HTTP на stdlib |
| 2 | REST, конкурентность и алгоритмы | v0.2 — REST и фоновые задачи |
| 3 | Docker и PostgreSQL | v0.3 — Postgres и Docker |
| 4 | Сервис: фреймворк, безопасность, Redis | v0.4 — настоящий сервис |
| 5 | Архитектура и устойчивость | v0.5 — рефакторинг и устойчивость |
| 6 | Продакшен: gRPC, Kafka, наблюдаемость | v1.0 — два сервиса |
| 7 | Финиш: портфолио и собеседование | — |

Каждая тема проходится в пять шагов: главный материал, дополнительные материалы, задание, тест, самопроверка «Умеешь».

На сайте есть список и граф тем, план на сегодня, прогноз даты финиша, повторение ошибок из тестов и поиск по карте, статьям и видео.

Прогресс хранится только в браузере. Чтобы не потерять его, время от времени скачивай копию через меню.

## Запуск у себя

Сборки нет. Открой `index.html` в браузере или подними любой статический сервер:

```
python3 -m http.server 8000
```

## Файлы

| Файл | Что в нём |
|------|-----------|
| `data.js` | вся программа: этапы, темы, материалы, задания, тесты |
| `app.js` | список тем, прогресс, тесты, повторение ошибок |
| `graph.js` | граф тем |
| `search.js`, `search-index.js` | поиск и его индекс |
| `scripts/` | проверки данных и ссылок |

## Как править карту

Формат записи темы описан в комментарии в начале `data.js`.

Прогресс учеников привязан к id и к номерам пунктов, поэтому:

- **id узлов и тем не меняй.** Порядок тем и узлов менять можно.
- **Новые вопросы теста добавляй только в конец.** Повторение ошибок ссылается на номер вопроса.
- **Пункты «Умеешь», чек-листов и milestone не удаляй и не переставляй.** Отметки хранятся по номеру пункта: текст правь на месте, новые пункты добавляй в конец.
- **Если тема переезжает в другой узел,** добавь пару «старый ключ → новый» в `RENAME` в конце `data.js`, тогда прогресс перенесётся.

## Проверки

```
python3 scripts/validate.py      # структура data.js
python3 scripts/check_links.py   # живы ли ссылки и видео, идёт несколько минут
```

`validate.py` запускается в GitHub Actions на каждый push и pull request, `check_links.py` — первого числа каждого месяца и вручную.

LeetCode и Cloudflare отвечают на автоматическую проверку кодом 403. Такие ссылки попадают в список «проверь руками» и сборку не роняют.

## Поисковый индекс

`search-index.js` хранит разделы статей и главы видео, по которым работает поиск. Скрипта, который его собирает, в репозитории нет. Темы и вопросы тестов ищутся всегда, а новые статьи и видео в поиске не появятся, пока индекс не пересобран.
